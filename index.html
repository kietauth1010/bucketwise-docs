How Bucketwise works

A field guide to running a bucket estimation session — from opening the board to saving real Story Points back to Jira.

1 2 3 5 8 Unestimated

01Overview

Bucketwise adds a bucket estimation board to any Jira Software project. Instead of estimating one issue at a time, a facilitator drags every issue in a chosen source into effort-size columns — 1, 2, 3, 5, 8, or Unestimated — then saves the whole batch to Jira's Story Points field in one action.

02Getting started

  1. Open any Jira Software project you have access to.
  2. Click the Bucketwise tab in the project's sidebar.
  3. The board loads with the project's Backlog issues by default.
No setup required

Bucketwise resolves the right Story Points field for your board automatically — there's nothing to configure before your first session.

03Choosing what to estimate

Use the source selector in the toolbar to switch between:

  • Backlog — issues not yet in any sprint (the default).
  • Whole board — every issue associated with the board, backlog and all sprints.
  • A specific sprint — any active or future sprint on the board.

The board always opens on Backlog on a fresh page load. Switching sources only reloads the columns, not the whole page.

04How estimation works

Each numeric column splits into two areas:

  • Base Stories (top, locked) — up to three reference tickets whose real Story Points value already equals that bucket. Click one to open it; you can't drag into or out of this row.
  • Estimating (bottom) — drag issues here to size them. Dragging only edits an in-progress draft; it never changes Jira data until you save.

A ticket's column is always derived fresh from its real Story Points value — there's no stale or remembered state across a page reload.

05Base Stories & Load similar tickets

Next to the Base Stories heading, click Load similar tickets to search the whole project for already-estimated issues to use as extra reference anchors. One click searches using the first Unestimated ticket's summary; a "search different text" link lets you enter a custom phrase. Matches are promoted to the top of their bucket's Base Stories column, even bumping out a previously displayed ticket.

06Saving your estimation

Click Save estimation to write the current board state back to Jira:

  • Only tickets whose bucket actually changed are updated — Base Stories tickets are never re-written.
  • Any ticket left in Unestimated has its Story Points field cleared.
  • If an issue fails to update — a permission or workflow validation error, for example — the rest still save, and the UI reports exactly which issues failed and why.

07Clicking a card

Clicking an issue card — as opposed to dragging it — opens Jira's native issue view in place, so you can check details without leaving the board.

08Permissions Bucketwise requests

Bucketwise only reads and writes Jira Software data needed to run an estimation session — issue details, board and sprint configuration, and the Story Points field. It does not access files, admin settings, or anything outside Jira Software. See the Data Security and Privacy Statement on the Marketplace listing for the full picture.
